# CRM Finance

Прототип Telegram Mini App для бухгалтерских услуг: налоговая отчётность и консультации
для ИП, самозанятых и ООО — резидентов РФ.

## Что внутри

`index.html` — статичный кликабельный прототип интерфейса (без бэкенда):

- **Анкета** — регистрация клиента с формой под тип (ИП / Самозанятый / ООО),
  включая поле "Интеграция с 1С"
- **Кабинет** — карточка клиента, статус проверки резидентства, ближайшие сроки отчётности
- **Чат** — AI-консультант по НК РФ с эскалацией к живому специалисту
- **Бухгалтеры** — отдельный живой чат-канал для консультаций с бухгалтером
  (без списка "свободен/занят" — просто общий тред)

Все данные в прототипе — статичные заглушки, ничего не сохраняется между сессиями.

## Локальный запуск

Файл полностью статичный — просто откройте `index.html` в браузере,
либо поднимите любой локальный сервер, например:

```bash
python3 -m http.server 8080
```

и откройте `http://localhost:8080`.

## Деплой на Vercel

1. Импортируйте этот репозиторий в Vercel (Add New → Project → Import Git Repository).
2. Никаких настроек сборки не требуется — это статический файл.
3. После деплоя получите https-ссылку вида `https://crm-finance.vercel.app`.

## Подключение к Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Настройте кнопку меню (`/setmenubutton`) или полноценное Mini App (`/newapp`),
   указав https-ссылку с Vercel.
3. Откройте бота в Telegram и проверьте прототип через кнопку меню.
